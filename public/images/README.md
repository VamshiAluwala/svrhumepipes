# Image uploads — SVR Hume Pipes

Drop your real photos into this folder (`public/images/`). Anything here is served on
the site at the URL `/images/<filename>`.

Once you've uploaded, tell Claude the filenames and it will wire each one into the
right spot on the page. Suggested names (use `.jpg` or `.webp`, landscape unless noted):

## High-impact spots (upload these first)
| Suggested filename            | Where it appears                                  |
|-------------------------------|---------------------------------------------------|
| `factory.jpg`                 | Homepage "Our Story" + About page (plant photo)   |
| `hero-yard.jpg`               | Main hero background (pipe yard / stacked pipes)   |
| `rcc-hume-pipes.jpg`          | Catalogue card — RCC Hume Pipes                    |
| `logo.png`                    | Header logo + favicon (transparent PNG preferred)  |

## Product / gallery photos (optional, add as available)
| Suggested filename            | Where it appears                                  |
|-------------------------------|---------------------------------------------------|
| `spun-casting.jpg`            | Manufacturing / process shots                     |
| `qc-lab.jpg`                  | Quality-control lab                               |
| `delivery-fleet.jpg`          | Trailer fleet / dispatch                          |
| `gallery-1.jpg` … `gallery-8.jpg` | Gallery page grid                             |

Tips: keep files under ~500 KB each (compress at e.g. squoosh.app), and use
descriptive lowercase names with hyphens (no spaces).
